# ParkingLot Project

This is the ParkingLot example project.

Build & test

```bash
cd ParkingLot
./mvnw test
./mvnw package
```

Run

```bash
# after packaging
java -jar target/*.jar
```

Notes
- Requires Java and Maven (the project includes the Maven wrapper `mvnw`).
- Source is under `src/main/java` and tests under `src/test/java`.
