# DesignPatterns

This repository holds example implementations of design patterns.

Main project:
- `ParkingLot/` — the Parking Lot project (Java/Maven). The code, pom.xml and build files live inside that directory.

Quick start

From the repository root:

```bash
# run tests
./ParkingLot/mvnw test

# build the project
./ParkingLot/mvnw package

# run the packaged jar (if the project produces one)
java -jar ParkingLot/target/*.jar
```

Notes
- The project files are stored under `ParkingLot/` to keep the repository organized.
- IDE files (e.g. `.idea/`) are intentionally left out of the repository; keep your local IDE config private.
